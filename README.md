# 🗣️ Text To Speech Generator

A simple and easy-to-use **Text-to-Speech Generator** built with **C#** and **System.Speech.Synthesis**.

The application converts written text into spoken audio using the voices installed on your Windows computer. It also allows you to select different voices, change speech speed and volume, stop speech, and save generated speech as a WAV audio file.

---

## ✨ Features

- 🗣️ Convert text into speech
- 🎙️ Select from installed Windows voices
- ⚡ Adjust speech speed
- 🔊 Adjust speech volume
- ⏹️ Stop speech
- 💾 Save generated speech as a `.wav` file
- 🖥️ Simple console-based interface
- 📁 Automatically saves WAV files to the Desktop
- ⚙️ Built using C# and .NET

---
